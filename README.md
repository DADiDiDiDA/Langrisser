# 梦幻模拟战 · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。
> 有需要直接 copy 改造即可，不用问我，也无需另行告知。
> 模拟器仅在 Mumu 模拟器上测试过；若运行在 PC 端，则仅在官方服（官服）测试过。

## 它能做什么

基于 `assets/interface.json` 配置，自动完成以下日常任务：

- **开始游戏**：进入游戏。
- **领取邮件**：自动领取邮件。
- **领取浮空之境**：自动领取浮空之境资源。
- **友情点领取**：赠送并领取友情点。
- **商店购买**：自动购买商店中的友情券。
- **竞技场**：执行竞技场快速作战挑战。
- **刷体力-兄贵健身房**：刷兄贵健身房体力，支持扫荡和连续作战。
- **刷体力-女神的试炼**：刷女神的试炼体力，支持扫荡和连续作战。
- **刷体力-安杰丽卡特训屋**：刷安杰丽卡特训屋体力，支持扫荡和连续作战。
- **刷体力-羁绊之地**：刷羁绊之地体力，支持扫荡和连续作战。
- **领取任务奖励（第一次）**：自动领取每日任务的奖励。
- **刷体力-律定之途**：刷律定之途体力，支持扫荡和连续作战。
- **友情池召唤一次**：使用友情券进行一次友情池召唤。
- **刷四次时空彼端**：进入时空彼端，扫荡 1-1/1-2 关卡四次。
- **完成世界事件**：做一次扫荡沙拉并完成当前可用的世界事件；不过餐吧要放到行政厅默认的位置，不然任务会卡住。
- **完成碎片扫荡**：完成每日的碎片扫荡。
- **领取任务奖励（第二次）**：自动领取每日任务的奖励。

> 在 MaaFramework 启动器的任务列表中勾选 / 取消对应项，即可自定义要运行的任务。

## 使用前的游戏设置

- 模拟器分辨率建议 **1298×767**，不要全屏 / 拉伸，否则会影响图像识别
- ⚠️ 事件刷新逻辑比较特殊：有时不会触发事件，导致对应的日常任务无法完成（属游戏机制，非脚本问题）
