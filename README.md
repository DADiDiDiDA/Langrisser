# Langrisser · 日常挂机

> 个人自用存档，基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 把对应游戏的日常任务自动化。
> 任务逻辑都写在 `assets` 里，欢迎直接 copy 改造。

## 它能做什么

基于 `assets/interface.json` 配置，自动完成以下日常任务：

- **开始游戏**
- **领取邮件**
- **领取浮空之境**
- **友情点领取**
- **商店购买**
- **竞技场**
- **刷体力-兄贵健身房**
- **刷体力-女神的试炼**
- **刷体力-安杰丽卡特训屋**
- **刷体力-羁绊之地**
- **领取任务奖励（第一次）**
- **刷体力-律定之途**
- **友情池召唤一次**
- **刷四次时空彼端**
- **完成世界事件**
- **完成碎片扫荡**
- **领取任务奖励（第二次）**

> 在 MaaFramework 启动器的任务列表中勾选 / 取消对应项，即可自定义要运行的任务。

## 使用前的游戏设置

- 模拟器分辨率建议 **1920 × 1080**，不要全屏 / 拉伸，否则会影响图像识别
- ⚠️ 事件刷新逻辑比较特殊：有时不会触发事件，导致对应的日常任务无法完成（属游戏机制，非脚本问题）
